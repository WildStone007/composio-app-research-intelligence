How the research agent works

01 / Discovery

DuckDuckGo search queries discover developer documentation, authentication references, API pages and MCP mentions.

02 / Extraction

Python rules extract authentication and API-related keyword signals. No LLM API calls are required.

03 / Evidence capture

Search titles, snippets, domains and URLs are stored with every application record.

04 / Human verification

Official documentation and credential-access requirements must be checked before upgrading a signal to a verified finding.

Verification and limitations

Discovery is not verification.

The current pipeline does not fetch and parse every official documentation page, validate credential issuance, test API requests or establish MCP functionality. Search snippets can be stale, incomplete or community-authored. No accuracy percentage is claimed at this stage.
